# Memory Bank — Financial Dashboard

## Descripción del producto

Dashboard interactivo de métricas financieras que permite visualizar ingresos, gastos, rentabilidad y tendencias a lo largo del tiempo. Genera datos mock deterministas para demostración y prototipado.

### Funcionalidades actuales

- Visualización de KPIs clave: ingreso total, gasto total, ganancia neta y margen de ganancia
- Gráfico de evolución mensual de ingresos vs gastos (líneas)
- Gráfico de margen de ganancia porcentual mensual
- Alternancia entre tema claro y oscuro
- Estados de carga con skeletons
- Manejo básico de errores de conexión con la API

### Funcionalidades del backend no consumidas por la UI

- Resumen agrupado por día/semana/mes
- Comparación entre períodos
- Alertas de gastos anómalos
- Top categorías por tipo de operación
- Facetas disponibles para filtrar
- Filtros por tipo de negocio (B2B/B2C)
